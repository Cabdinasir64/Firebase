# Firebase Learning Folder ⚡

This folder contains my **Firebase practice projects** where I explore and learn about **Firebase Authentication** and **Firestore**.  
The goal is to understand how to integrate Firebase services into React projects and manage real-time data.

---

## 🛠 Topics Covered

### Firebase Authentication
- Email & Password authentication  
- Google Sign-In  
- Facebook Sign-In  
- Password reset functionality  
- User profile management (update name, email, and photo)  

### Firestore
- Adding, reading, updating, and deleting documents  
- Real-time data synchronization  
- Querying collections with filters  
- Pagination and sorting data
